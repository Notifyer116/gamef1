# Источники и игровые допущения

Снимок открытых данных проверялся 15 октября 2026 года. Игра работает автономно и не обновляет составы через интернет. Реальные структуры команд различаются: четыре одинаковых игровых кресла являются упрощением. Управляющий директор, руководитель гоночной команды и руководитель аэродинамического направления могут занимать соответствующий игровой слот, даже если буквальное название их должности другое.

## Календарь и фотографии

[Официальный календарь F1](https://www.formula1.com/en/racing/2026), [FIA — спринтерский календарь 2026](https://www.fia.com/news/fia-and-formula-1-announce-2026-sprint-calendar). В игре используется фиксированная последовательность 23 этапов и шести спринтов. Игровые дни, базовые времена, вероятность дождя и износ — параметры модели, а не реальная телеметрия.

21 фотография получена с Wikimedia Commons. Это реальные спутниковые, панорамные и гоночные снимки, преимущественно Planet Labs / SkySat. Для каждого файла в `photo-credits.json` указаны автор, страница оригинала, URL изображения, лицензия и ссылка на её условия. Снимки показывают трассы в разные годы, не обязательно конфигурацию 2026. В интерфейсе изображение может кадрироваться под карточку, исходный встроенный файл не перерисован.

Мадрид: [галерея MADRING на Formula1.com, 19 августа 2026](https://www.formula1.com/en/latest/article/gallery-madring-circuit-shares-new-photos-ahead-of-madrids-maiden-grand-prix.vTxESDb75rcZnMyPrf9Ul). Лас-Вегас: [официальная страница этапа](https://www.formula1.com/en/racing/2026/las-vegas). Права на эти два снимка остаются у правообладателей; открытый доступ к странице не является свободной лицензией на распространение. Эта сборка подготовлена для указанного пользователем личного использования. Перед публичным распространением замените эти материалы либо получите разрешение; марки F1 и команд также принадлежат их владельцам.

## Что придумано для игры

Рейтинги, зарплаты, настрой, начальные сроки договоров и отступные не являются сведениями о реальных контрактах. Возраст персонала, начальная сработанность, характеристики болидов, стоимость и сроки деталей, вероятность неудачи, моторные показатели, доходы и лимит разработки также заданы для игрового баланса. Свободные вымышленные специалисты, персонал собственной команды и новые поколения отмечены в интерфейсе `*`. Возможность нанять реального человека — игровой механизм.

## Портреты пилотов, обновление 2.1

Для 22 пилотов стартового грида 2026 и Yuki Tsunoda добавлены фотографии из общедоступных репозиториев [Subin-Ju/f1-driver-images](https://github.com/Subin-Ju/f1-driver-images) и [teresakrchen/f1-driver-image-2026](https://github.com/teresakrchen/f1-driver-image-2026). Некоторые снимки показывают форму предыдущего сезона. Для каждого портрета сохранены URL исходного файла с точным коммитом, SHA-256 загруженного оригинала и описание преобразования в `driver-photo-credits.json`. Портреты конвертированы в PNG, уменьшены и кадрированы для интерфейса.

В этих репозиториях не указана свободная лицензия на сами фотографии. Открытая доступность файла и лицензия на программный код не передают права на изображение. Права остаются у соответствующих правообладателей; условия личного использования проекта не меняются.

## Логотипы команд, обновление 2.2

Оригинальные знаки McLaren, Ferrari, Red Bull, Mercedes, Aston Martin, Alpine, Haas, Racing Bulls и Williams получены из общедоступного репозитория [slowlydev/f1-dash](https://github.com/slowlydev/f1-dash/tree/main/dashboard/public/team-logos). Знаки Audi и Cadillac — из [shvmmshr/f1lytics](https://github.com/shvmmshr/f1lytics/tree/main/public/teams). SVG преобразованы в PNG для встроенных ресурсов Windows Forms; рисунок знаков сохранён. Для Audi и Cadillac используются оригинальные эмблемы производителей.

Для каждого файла в `team-logo-credits.json` указаны точный коммит источника, URL и SHA-256 оригинала. Логотипы являются товарными знаками их владельцев; доступность исходного файла не передаёт права на товарный знак. У собственной вымышленной команды отдельная нейтральная отметка «+».

## Изображения шин, обновление 2.2

Изображения пяти составов получены из общедоступного репозитория [Nicxe/f1-sensor-live-data-card](https://github.com/Nicxe/f1-sensor-live-data-card/tree/main/images). Использованы оригинальные PNG без изменений: soft, medium, hard, intermediate, wet. Точный коммит, URL и контрольные суммы исходных файлов перечислены в `tyre-photo-credits.json`. Лицензия исходной поставки MIT включена в `tyre-assets-LICENSE.txt`; знаки Pirelli принадлежат их владельцам.

Технические рисунки 15 деталей созданы для этого интерфейса средствами векторной графики (`Source/DevelopmentUI.cs`); сторонние фотографии деталей не использованы. Профили требований трасс, веса десяти характеристик и эффективность новинок — параметры игрового баланса, не официальная телеметрия.
